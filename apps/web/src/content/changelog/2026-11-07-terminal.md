---
title: v0.2 — 转向终端 / IDE 风
date: 2026-11-07
---

v0.1 的「像素等宽 × 衬线排版」方向被判定为丑，整体推翻重来。

### 设计语言

- **底更暗、面板实心**：背景收到 `#0b0a08`，面板从半透明改成实底 `#1e2530`，层次靠两级实色拉开。
- **hairline 加实**：`--line` 从看不见提到看得见，描边一律 1px 内描边（box-shadow，不用 border）。
- **网格降噪**：小格 20px / 大格 100px，透明度压到 3% / 6%——能感觉到，看不见。
- **衬线近乎清零**：Source Serif 4 只留给拉丁引文与 hero 强调词。
- **中文全走 mono**：mono 栈里中文回落 PingFang SC 等系统黑体，**永不落到宋体**。
- **圆角 3px 封顶**，加终端语义 token（`--w-c-prompt` / `--w-c-caret` / `--w-c-chrome`）。

### 站点

- 产品页、文档站、组件总览、changelog、404 全部重做为终端 / IDE 语言。
- 每个组件页加 **dark / light 双 demo 面板**——两种主题并排看，不用切。

### 工程

- **token 单一事实源**换成 DTCG 格式的 `packages/tokens/tokens.json`，`pnpm tokens:build` 编译出 CSS / Tailwind preset / tweakcn JSON，`pnpm tokens:check` 在 CI 里挡住漂移。
- 新增 `scripts/oklch-to-hex.mjs`——hex ↔ OKLCH 双向换算，色值可追溯回设计稿。
- **组件目录**抽成 `registry/catalog.json`，站点文档、registry 元数据、agent 索引读同一份。
- 新增 `design/principles.md`（设计原则）与 `design/decisions.md`（决策日志）。
- **agent 界面**：`/llms-full.txt` + 每页 `.md` 孪生（`/docs/components/button.md` 之类），由 `src/data/markdown.ts` 生成，与网页版同源。

> Components that grow anywhere.
